# 患者状态监测与风险预警工作流

一个由 **Kimi Code CLI 自动化执行**的患者状态监测工作流：把 `原始资料/` 文件夹里的检验报告图片、病历截图、家属观察记录，自动整理成 **病程时间线 → 当前状态评估 → 风险预警 → 家属可读报告 → 深度文献调研**。

适用场景：肿瘤放化疗期间的家庭监测。任何家人把新检查资料丢进文件夹，对 AI 说一句"执行工作流"即可完成一次完整更新。

## 目录结构

```
患者状态监测工作流/
├── workflow.yaml          # 工作流定义（阶段、输入输出、验收标准、红线）
├── README.md              # 本说明
├── SETUP.md               # 新手上手指南（安装、目录结构、FAQ）
├── setup.py               # 初始化向导（建目录 + 检查环境）
├── prompts/               # 各阶段执行提示词（Kimi 按此执行）
│   ├── W1_资料摄取与时间线.md
│   ├── W2_当前状态评估.md
│   ├── W3_风险预警预测.md
│   ├── W4_报告生成.md
│   └── W5_深度调研.md      # 最后一步：Deep Research（也可独立复制到其他工具用）
├── schemas/               # 各阶段输出的 JSON 结构定义
│   ├── timeline.schema.json
│   ├── status.schema.json
│   └── risk.schema.json
├── data/                  # 【实例数据·勿公开】时间线与患者问题清单
│   ├── patient_timeline.json
│   └── 患者问题清单_<日期>.md
└── output/                # 【实例数据·勿公开】每次运行的产出
    ├── status_assessment_<日期>.json   # 状态评估
    ├── risk_prediction_<日期>.json     # 风险预警
    ├── 患者状态报告_<日期>.md / .pdf    # 家属版报告 ★先看这个
    └── deep_research_<日期>.md         # 深度调研（含 PMID 核实文献）
```

## 工作流阶段

```
W1 资料摄取 → W2 状态评估 → W3 风险预警 → W4 家属报告 → W5 深度调研（最后一步）
```

- **W1**：扫描 `原始资料/`，逐项提取检验数值，增量更新病程时间线（含重命名/转录副本去重规则；看不清标 `unclear`，禁止猜测）。
- **W2**：以时间线最新日期为基准，逐项解读最新检验、与上次对比趋势、CTCAE 参考分级、合并症与数据缺口。
- **W3**：预测未来 1-4 周风险（感染/出血/胃肠道/代谢/肾脏/血液/营养/免疫不良反应/治疗中断/肿瘤进展 十域全覆盖），每条含等级、依据、机制、监测项、就医红旗；高风险可附 PubMed 核实的循证文献。
- **W4**：合成家属可读报告（当前状态 / 警惕问题表 / 日常注意 / 复诊问题清单 / 数据缺口）。
- **W5**：按患者问题清单做循证调研（共识 + 2024-2026 新进展 + 争议空白 + 适用性提示），文献必须 PMID 核实。

## 如何使用

> 👋 **新用户请先读 [SETUP.md](SETUP.md)** 并运行 `python setup.py` 完成初始化。

1. 把新的检验报告照片/病历截图放进 `原始资料/` 文件夹。
2. 对 Kimi 说：**"执行患者状态监测工作流"** —— 依次执行 W1→W5，`output/` 生成以基准日命名的新报告。
3. 快速模式（跳过耗时的 W5）：**"执行工作流，跳过W5"**。
4. 无新资料仅重分析：**"跳过W1，重新执行W2-W5"**。
5. 单独使用 Deep Research：打开 `prompts/W5_深度调研.md`，复制"调研 Prompt 正文"，粘贴到任意 Deep Research 工具（使用前请更新病例背景中的数值）。

## 隐私红线（已写入 workflow.yaml，每次执行强制遵守）

- 不提供具体医疗处方或剂量建议；不替代医生判断
- 不编造数据；看不清的标记 unclear / data_gap
- **家属版报告（W4）中不出现姓名、住院号、电话等直接身份信息**
- 注意：`data/` 与 `output/` 仍可能含床号、影像号等准标识信息，**不要公开**

## 发布/分享注意

- 本仓库（workflow.yaml / prompts / schemas / README）不含患者直接身份信息，可公开分享。
- `data/`、`output/`、`原始资料/` 为实例数据，含准标识信息（床号、影像号、完整病程），**禁止上传公开仓库**；本文件夹自带的 `.gitignore` 已将其排除。
- 推到 GitHub 前请确认 `.gitignore` 生效（`git status` 不应列出 data/output/原始资料）。
