# W1 资料摄取与时间线更新 — 执行提示词

## 你的任务
扫描 `原始资料/` 文件夹，把所有医疗资料转换为结构化的时间线事件，**增量更新** `患者状态监测工作流/data/patient_timeline.json`。

## 执行步骤
1. 列出 `原始资料/` 全部文件，按修改时间排序。
2. 读取 `data/patient_timeline.json`（若不存在则以空数组初始化）。以 `source_file` + `date` 作为去重键，已存在的文件跳过。
   - **文件重命名处理**：若发现新文件名与时间线中某事件的报告内容一致（同一检查日期、同一组数值），则只更新该事件的 `source_file` 为新文件名，不重复录入。
   - **转录副本处理**：若新文件是既有报告的人工转录文本（如把 PDF 报告逐字打成 txt，内容一致），不新建事件，只把该文件追加到既有事件的 `extracted_data.related_files` 并在 summary 注明去重。
3. 对新文件逐一处理：
   - **图片**（.jpg/.png）：用读图能力识别。检验报告逐项提取：项目名、缩写、结果、单位、参考区间、↑/↓ 标记；门诊病历提取：就诊日期、科别、主诉、病情变化、诊断、处理意见、用药。
   - **文本**（.txt/.md）：提取日期线索与事实性内容（症状、医嘱、用药）。
4. 每个文件产出 1 个或多个事件，追加到时间线，按 `date` 升序排列后写回 JSON。

## 事件 JSON 格式（遵循 schemas/timeline.schema.json）
```json
{
  "date": "2026-08-28",
  "type": "lab_blood | lab_urine | lab_liver_kidney | imaging | outpatient | chemo | immunotherapy | radiotherapy | symptom_note | doctor_chat | other",
  "source_file": "原始资料/xxx.jpg",
  "summary": "一句话概括",
  "extracted_data": { }
}
```
- `extracted_data` 对检验事件为 `{"items": [{"name","abbr","value","unit","ref","flag"}]}`；
- 对门诊/治疗事件为 `{"department","diagnosis","orders","medications"}` 等相应字段。

## 硬性规则
- 日期一律取**资料内部出现的日期**（如报告接收日期、就诊日期），不要用文件修改时间代替；资料内无日期时填 `null` 并在 summary 注明"日期不明"。
- 看不清/无法确认的数值：该条目标记 `"flag": "unclear"`，**禁止猜测**。
- 不解读、不下结论——W1 只做事实提取。
